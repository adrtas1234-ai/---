AION Mobile — стартовая PWA-версия для iPhone

ЧТО УЖЕ РАБОТАЕТ
- Мобильный интерфейс чата.
- История сообщений хранится локально в Safari.
- Настройки подключения к совместимому OpenAI-style API.
- PWA manifest и service worker для добавления на экран «Домой» и кеширования оболочки.

ЧЕГО ПОКА НЕТ
- В архив не встроена языковая модель.
- Нет собственного сервера, бесплатного API или интернет-поиска.
- PWA-оболочка может открываться офлайн после первого посещения, но ответы модели без сети/локальной модели не генерируются.
- Введённый API-ключ сохраняется в localStorage. Это удобно для личного теста, но менее безопасно, чем серверный proxy. Не используй эту схему для публичного приложения.

КАК ЗАПУСТИТЬ ТОЛЬКО С IPHONE
1. Нужен бесплатный HTTPS-хостинг статических файлов. Примеры: GitHub Pages или Netlify. Бесплатные тарифы и условия могут меняться.
2. На GitHub можно создать репозиторий через Safari, загрузить файлы архива (предварительно распаковать архив в приложении «Файлы») и включить Pages в Settings → Pages → Deploy from a branch → main / root.
3. Дождись публикации сайта и открой выданный HTTPS-адрес в Safari.
4. Нажми Поделиться → На экран «Домой» → Добавить.
5. Запускай AION с иконки на главном экране.

ВАЖНО
Сам по себе GitHub Pages не запускает модель и не выдаёт API. Для реальных ответов нужен отдельный провайдер модели с API-доступом или свой сервер. Условия бесплатного доступа, лимиты и доступность зависят от провайдера. Не вставляй ключ в публичный репозиторий. В текущей версии ключ хранится только в локальном хранилище браузера; для лучшей защиты далее следует добавить backend proxy.

ПЕРВАЯ ПРОВЕРКА
Открой index.html локально для предварительного просмотра интерфейса, но установка как PWA и service worker требуют HTTPS (или localhost).
